# Asymmetric Slab Waveguide Solver

A MATLAB project for analyzing guided modes in an asymmetric slab waveguide.

## Project Overview

This project numerically studies the guided modes of an asymmetric slab waveguide for both TE and TM polarizations.

## Key Features

- Calculates effective refractive indices of guided modes.
- Solves the waveguide mode equations using numerical root-finding.
- Studies the normalized propagation constant as a function of the normalized frequency \(V\).
- Compares TE and TM mode behavior.

## Tools Used

- MATLAB
- Numerical methods and root-finding
- Optical waveguide theory

## Learning Objectives

This project explores how waveguide geometry and refractive indices determine optical confinement and guided-mode propagation.
