# Simulation Results

This folder contains the numerical results from the asymmetric slab-waveguide solver.

## Results

The solver plots the normalized propagation constant \(b\) against the normalized frequency \(V\) for TE and TM modes.

- **TE modes:** Transverse electric modes supported by the slab waveguide.
- **TM modes:** Transverse magnetic modes supported by the slab waveguide.
- **Horizontal axis:** Normalized frequency \(V\).
- **Vertical axis:** Normalized propagation constant \(b\).

## Simulation parameters

The example simulation uses:

- Core refractive index: 1.50
- Upper cladding refractive index: 1.45
- Lower cladding refractive index: 1.44
- Core thickness: 1 μm

The results illustrate the modal dispersion behaviour for the selected waveguide parameters.
